# ⚽ トレーニングシステム

カメラを使った練習サポートアプリ。**映像は端末の中だけで処理し、保存もクラウド送信もしない**。
iPhone / iPad の Safari を主な対象にした Web アプリ（PWA）。一度開けばオフラインでも動く。

公開: https://grande-training.web.app （Firebase Hosting、サイト `grande-training`。戦術ボードと同じプロジェクト）

## ページ

| ページ | 内容 |
|---|---|
| `index.html` | メニュー |
| `timing.html` | ⏱ タイム計測（10m / 20m / 30m スプリント、505 アジリティ） |

| `heading-classic.html` | 🧠 ヘディング旧版（かぞえる／フォーム分析）。メニューからは外した |

| `lifting-counter.html` `jump-meter.html` `delay-replay.html` | 以前からのページ（TensorFlow.js を CDN から読むのでオンラインが必要） |

## 仕組み

### タイム計測（`js/timing-core.js`）
光電管と同じ考え方。画面に引いた線の位置の細い帯（左・中央・右の 3 本、腰〜胸の高さ）を毎コマ見て、
背景と違う画素が帯に増えた瞬間＝体が線を切った瞬間とする（`StripDiff` → `Gate`）。
AI を使わないので 60fps で回せ、コマとコマの間は直線で補う。`requestVideoFrameCallback` の `mediaTime` を時刻に使う。
- `SprintTimer`: スタート線→ゴール線（`lines`）、または合図の音→ゴール線（`signal`）
- `Agility505`: 計測線を出て、折り返し線の帯に体が入り、計測線に戻ったら終了。届かずに戻ると無効
- 背景は動きが無い間ゆっくり覚え直す。線を動かしたときと「背景を覚え直す」で作り直す
- 「テスト」で帯の占有率と反応が見える。感度スライダーで背景との差のしきい値を変える

### ジャンプヘッド道場（`heading.html`、`js/heading-form.js`、`js/heading-log.js`）
目的は「選手がその場で自分のジャンプヘッドを振り返り、次の 1 本に活かす」こと。中学生（U-13〜15）向け。真横から撮る前提。
- **撮りっぱなし**: カメラのコマを JPEG で直近 4.5 秒メモリに持ち、姿勢（lite）を 2 コマに 1 回見る。足が地面から浮いて 0.2 秒以上たって着地したら
  （`JumpTrigger`。走っているときの一瞬の浮きは数えない）、踏み切り 1.2 秒前〜着地 0.45 秒後を切り出して解析する。画面に触らなくてよい
- **解析**（`analyzeRep`）: 切り出したコマに姿勢（既定 full）とボールの検出をかける。踏み切りの前は 3 コマに 1 回
  - 跳んだ高さ = 滞空時間から（g·T²/8。体の大きさに左右されない）。**頂点 = 滞空の真ん中**（腰の放物線の頂点とも照合）
  - 当たった瞬間: ボールあり＝頭で跳ね返った瞬間（`HeadingCounter`）／キャッチ＝ボールが手首の近くで止まった瞬間／ボールなし＝反りから上体がいちばん速く前へ戻った瞬間
  - **頂点との差**（当たった − 頂点）。◎ は −0.07〜+0.03 秒（上がりきる直前〜頂点）。頂点より下がった高さは ½gt²
  - 反り（上体の後傾の最大）、振りの大きさと速さ、**体で振った割合**（振り戻しのうち上体の分。首だけで振ると下がる）、あごの上がり、
    腕の振り上げ（踏み切り直後の手首）、ひじを引いた量、踏み切りの膝、助走の速さ、着地の膝、両足の着地のずれ、打点（身長から px→cm）
  - 局面（踏み切り・空中姿勢・タイミング・体で振る・当てる場所・着地）ごとに ◎○△。**ひとことは 1 本に 1 つ**（テーマの局面。無ければタイミング優先で一番の課題）、
    体の外に意識を向ける言い方で。着地が △ のときは安全のために別に一言
- **自分で予想**: 結果の前に「早かった／ちょうど／遅かった」を答え、実際と比べる（感覚の一致率を残す）。3 本続けて ◎ なら答えを隠して自分で振り返らせる（助言を減らす）
- **ステップ**（`STEPS`）: 弓を引く → 一番高いところで放つ → 体で叩く → 最高点キャッチ → 助走から放つ → ジャンプヘッド → 助走ジャンプヘッド。
  テーマの局面が直近 5 本で ◎ 3 本なら合格して次が開く。前半はボールなし／キャッチなので頭に負担がない
- **安全**: ボールが頭に当たった本数を週（月曜はじまり）で数え、JFA「育成年代でのヘディング習得のためのガイドライン」の U-13〜15 の目安（ペアが投げたボール 週 10 回）を既定の上限にする（「きろく」で選手ごとに変更）
- **ふりかえり**: 終わるときに局面ごとの ◎ の割合・気づき（選んで＋自由記述）・次のテーマを残し、次に開いたときに出す。「頭や首が痛い」を選ぶと中止を促す
- ログは `localStorage` の `trainingsystem.heading.v2`（1 本ごとの数字と評価、合格、気づき。映像は残さない）。練習ごとのベスト（ジャンプ・打点・頂点とのずれの平均・ヘディング本数）は「きろく」にも入れる
- 「🎬 見本」: カメラなしで棒人間の 1 本を解析して結果画面を見せる
- 数字の目安（◎○△ のしきい値）は仮。うまい選手の映像で合わせていく

### ヘディング旧版（`heading-classic.html`、`js/heading-core.js`）
MediaPipe Tasks Vision（`vendor/mediapipe/`、Apache 2.0）の PoseLandmarker（33 点）と ObjectDetector（EfficientDet-Lite0、sports ball）。
モデルは `models/` に置いてあるのでオフラインで動く。`js/vision.js` は道場と共通。
- かぞえる: 落ちてきたボールが頭の近くで跳ね返った／いちばん近づいて離れた瞬間を 1 回にする（`HeadingCounter`）。頭の陰で一瞬見えなくても数える
- フォーム分析: 撮影中は JPEG のコマを端末のメモリに貯め（最大 10 秒）、撮り終えてから全コマに姿勢とボールの検出をかける（`analyzeClip`）

### 記録（`js/records.js`）
選手と記録は `localStorage` に保存（`trainingsystem.records.v1`）。CSV は BOM 付き UTF-8。

### オフライン（`sw.js`）
最初に開いたときにページ・部品・モデル（合計約 45MB）を端末に入れる。ページは「まずネット、だめなら端末」、モデルは「端末のものを先に」。
`VERSION` を上げると入れ直す。

## 開発
- テスト: `node --test "test/*.test.js"`（計算部分だけ。DOM・カメラは使わない）
- 手元で動かす: 静的サーバーで開く（例: `npx http-server . -p 8790 -c-1`）。カメラは HTTPS か localhost でしか使えない
- 公開: `firebase deploy --only hosting:training`
